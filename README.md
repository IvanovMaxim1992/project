КратКое описание проектов, которые я выполнил во время обучения в Яндекс практикум.

### 1. **Прогнозирование удоя и вкуса молока коров**
   - **Задача:** Создание моделей для прогнозирования удоя коров и вкуса молока.
   - **Инструменты и библиотеки:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn.
   - **Достигнутый результат:** Разработаны модели, предсказывающие удой и вкус молока с высокой точностью, что помогает фермерам оптимизировать поголовье.

### 2. **Определение стоимости автомобилей**
   - **Задача:** Создание модели для предсказания стоимости автомобилей.
   - **Инструменты и библиотеки:** Pandas, NumPy, Scikit-learn, LightGBM, Matplotlib, Seaborn.
   - **Достигнутый результат:** Модель линейной регрессии и LGBMRegressor показали хорошие результаты по метрикам RMSE, MAE и R2.

### 3. **Классификация токсичных комментариев с использованием BERT**
   - **Задача:** Разработка модели для автоматического выявления токсичных комментариев.
   - **Инструменты и библиотеки:** Pandas, NumPy, Scikit-learn, Transformers, PyTorch, Optuna.
   - **Достигнутый результат:** Модель PassiveAggressiveClassifier показала высокую точность и F1-метрику на тестовой выборке.

### 4. **Предсказание оттока клиентов телекоммуникационной компании**
   - **Задача:** Разработка модели для предсказания оттока клиентов.
   - **Инструменты и библиотеки:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, LightGBM, CatBoost.
   - **Достигнутый результат:** Модель достигла высокого значения ROC AUC, что позволяет эффективно предсказывать отток клиентов.

### 5. **Предсказание стоимости жилья**

### 6. **Оценка Риска ДТП для Каршеринговой Компании**
