# Мои проекты в рамках обучения на Яндекс Практикуме

## Список проектов

### 1. Прогнозирование удоя и вкуса молока коров
- **Инструменты:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
- **Решение:** Создана система прогнозирования, помогающая фермерам оптимизировать поголовье и улучшить качество продукции.

### 2. Определение стоимости автомобилей
- **Инструменты:** Pandas, NumPy, Scikit-learn, LightGBM, Matplotlib, Seaborn
- **Решение:** Разработан инструмент для точной оценки рыночной стоимости автомобилей при продаже/покупке.

### 3. Классификация токсичных комментариев
- **Инструменты:** Pandas, NumPy, Scikit-learn, Transformers, PyTorch, Optuna
- **Решение:** Внедрена автоматическая система модерации контента, поддерживающая положительную атмосферу платформы в реальном времени.

### 4. Предсказание оттока клиентов телекома
- **Инструменты:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, LightGBM, CatBoost
- **Решение:** Создан инструмент прогнозирования оттока, позволяющий компании своевременно принимать меры по удержанию клиентов.

### 5. Предсказание стоимости жилья
- **Инструменты:** Pandas, NumPy, Scikit-learn, PySpark, Matplotlib, Seaborn
- **Решение:** Разработана модель оценки недвижимости для более точного ценообразования на рынке жилья.

### 6. Оценка риска ДТП
- **Инструменты:** Pandas, NumPy, Scikit-learn, LightGBM, CatBoost, Matplotlib, Seabern
- **Решение:** Создана система оценки рисков для каршеринговой компании, повышающая безопасность поездок.

### 7. Мэтчинг товаров
- **Инструменты:** Pandas, NumPy, Faiss, Annoy, Qdrant, Scikit-learn, Matplotlib, Seaborn
- **Решение:** Реализована эффективная система поиска похожих товаров, улучшающая пользовательский опыт на маркетплейсе.

### 8. Выбор локации для скважины
- **Инструменты:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Bootstrap
- **Решение:** Определен оптимальный регион для разработки скважин с минимальными рисками и максимальной прибылью.

### 9. HR-аналитика 
- **Инструменты:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, DecisionTreeRegressor
- **Решение:** Созданы модели прогнозирования удовлетворенности и оттока сотрудников для HR-менеджмента.

### 10. Сопоставление текста и изображения
- **Инструменты:** Pandas, NumPy, PyTorch, Transformers, CLIP, Matplotlib, Seaborn
- **Решение:** Разработан механизм поиска изображений по текстовому запросу для улучшения пользовательского опыта.

### 11. Анализ аренды самокатов
- **Инструменты:** Pandas, NumPy, Scipy, Matplotlib, Seaborn, T-test
- **Решение:** Выявлены ключевые факторы использования сервиса и даны рекомендации по улучшению бизнеса.

### 12. Прогнозирование рентабельности стартапов
- **Инструменты:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, LightGBM, CatBoost
- **Решение:** Создан инструмент оценки инвестиционной привлекательности стартапов для инвесторов.

### 13. Персонализация в интернет-магазине
- **Инструменты:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, LightGBM
- **Решение:** Разработана система персонализированных предложений, увеличивающая покупательскую активность.

### 14. Температура звезд
- **Инструменты:** Pandas, NumPy, PyTorch, Matplotlib, Seaborn, Optuna
- **Решение:** Создана модель для точного определения температуры звезд, полезная для дальнейших астрофизических исследований.
