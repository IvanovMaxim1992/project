# Oil Region Selection: Прогноз запасов и анализ рисков

| **Раздел**          | **Детали**                                                                                                                                                                                                 |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цели проекта**     | 1. Прогноз запасов нефти в трех регионах с использованием регрессии.<br>2. Определение оптимального региона для бурения скважин.<br>3. Оценка рисков и прибыли с помощью метода Bootstrap. |
| **Данные**           | - **Регионы**: 3 региона, по 10,000 месторождений в каждом.<br>- **Признаки**: f0, f1, f2 (геологические параметры), product (запасы нефти).<br>- **Тестовые наборы**: Отдельные данные для каждого региона. |
| **Инструменты**      | - **Python**: pandas, numpy, scikit-learn, matplotlib, seaborn.<br>- **Модели**: LinearRegression.<br>- **Анализ рисков**: Bootstrap, расчет ROI, RMSE, MAE. |
| **Ключевые этапы**   | 1. Загрузка и предобработка данных (масштабирование, разделение на регионы).<br>2. Обучение моделей для прогнозирования запасов.<br>3. Расчет метрик (RMSE: **37.6**, MAE: **29.4**).<br>4. Анализ достаточности запасов для безубыточности.<br>5. Bootstrap для оценки прибыли и рисков (1000 симуляций). |
| **Результаты**       | - **Лучший регион**: Регион 1 (средняя прибыль: **450 млн. руб.**, риск убытков: **1.2%**).<br>- **Критический порог**: Безубыточный объем — **111 тыс. баррелей**.<br>- **Топ-200 скважин**: Средний запас в регионе 1 — **139 тыс. баррелей** (достаточно для безубыточности). |
| **Сложности**        | - Низкие средние запасы в регионах (ниже безубыточного порога).<br>- Необходимость выбора топ-200 скважин для повышения рентабельности.<br>- Учет экономических параметров (бюджет, стоимость разработки). |
| **Бизнес-ценность**  | - Рекомендация региона с минимальными рисками (1.2%) и максимальной прибылью.<br>- Стратегия разработки месторождений на основе данных.<br>- Экономия ресурсов за счет отказа от нерентабельных регионов. |
