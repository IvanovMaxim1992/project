# Toxic Comment Classification: Анализ и модерация контента

| **Раздел**          | **Детали**                                                                                                                                                                                                 |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цели проекта**     | 1. Классификация комментариев на токсичные/нетоксичные с использованием NLP и глубокого обучения.<br>2. Автоматизация модерации контента для платформы «Викишоп».<br>3. Анализ ключевых паттернов в токсичных комментариях. |
| **Данные**           | - **Обучение**: 159,292 комментария с текстом и меткой токсичности (1/0).<br>- **Тест**: Отдельный набор данных для валидации модели.<br>- **Признаки**: Оригинальный текст, очищенный текст, лемматизированные данные. |
| **Инструменты**      | - **Python**: pandas, numpy, scikit-learn, matplotlib, seaborn, NLTK, SpaCy, transformers (BERT).<br>- **Обработка текста**: Регулярные выражения, лемматизация, удаление стоп-слов.<br>- **Модели**: BERT, LogisticRegression, TF-IDF. |
| **Ключевые этапы**   | 1. Очистка данных (удаление шума, HTML-тегов, спецсимволов).<br>2. Лемматизация с использованием SpaCy.<br>3. Визуализация токсичных паттернов (топ-20 слов: *fuck, your, you*).<br>4. Обучение BERT и сравнение с baseline-моделями. |
| **Результаты**       | - **BERT**: F1-score **0.89** на тестовой выборке.<br>- **Baseline (TF-IDF + LR)**: F1-score **0.82**.<br>- **Ключевые слова**: Высокая частота слов *fuck*, *your*, *you* в токсичных комментариях. |
| **Сложности**        | - Дисбаланс классов (токсичных комментариев меньше).<br>- Обработка сарказма и контекстных зависимостей.<br>- Высокая ресурсоемкость BERT.                                          |
| **Бизнес-ценность**  | - Снижение нагрузки на модераторов за счет автоматической фильтрации.<br>- Улучшение пользовательского опыта на платформе.<br>- Возможность интеграции в реальном времени для мгновенного блокирования токсичного контента. |
