# Product Matching: Оптимизация поиска похожих товаров

| **Раздел**          | **Детали**                                                                                                                                                                                                 |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цели проекта**     | 1. Выбор оптимальной модели для поиска наиболее похожих товаров (мэтчинг).<br>2. Сравнение методов ANNOY, FAISS и Qdrant по скорости и точности.<br>3. Повышение эффективности рекомендательной системы маркетплейса. |
| **Данные**           | - **Базовый датасет**: 291,813 строк, 72 числовых признака (векторные представления товаров).<br>- **Валидационный набор**: 9,999 строк с аналогичной структурой.<br>- **Целевая метрика**: accuracy@5. |
| **Инструменты**      | - **Python**: pandas, numpy, scikit-learn, FAISS, ANNOY, Qdrant.<br>- **Предобработка**: Масштабирование (StandardScaler), удаление слабокоррелирующих признаков.<br>- **Оптимизация**: GridSearchCV для подбора параметров индексов. |
| **Ключевые этапы**   | 1. Анализ корреляции признаков (удалены признаки с корреляцией < 0.3).<br>2. Масштабирование данных для улучшения работы моделей.<br>3. Тестирование ANNOY, FAISS, Qdrant: построение индексов и поиск соседей.<br>4. Оценка времени построения, поиска и точности (accuracy@5). |
| **Результаты**       | - **ANNOY**: Время построения — **0.99с**, поиск — **0.24с**, accuracy@5 — **7.49%**.<br>- **FAISS**: Время построения — **0.046с**, поиск — **125с**, accuracy@5 — **23.75%**.<br>- **Qdrant**: Время построения — **0.12с**, поиск — **2.1с**, accuracy@5 — **18.9%**. |
| **Сложности**        | - Баланс между скоростью и точностью (FAISS точнее, но медленнее).<br>- Работа с высокоразмерными данными (72 признака).<br>- Подбор параметров индексов (n_cells, nprobe) для оптимизации. |
| **Бизнес-ценность**  | - Улучшение пользовательского опыта за счет релевантных рекомендаций.<br>- Сокращение времени обработки запросов (ANNOY и Qdrant показали высокую скорость).<br>- Возможность интеграции в реальном времени для динамического обновления каталога. |
