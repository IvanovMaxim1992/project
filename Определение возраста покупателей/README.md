# Определение возраста покупателей: Анализ и обучение модели

| **Раздел**          | **Детали**                                                                                                                                                                                                 |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цели проекта**     | 1. Прогнозирование возраста покупателей на основе изображений лиц.<br>2. Анализ распределения возрастов в датасете.<br>3. Разработка модели глубокого обучения для минимизации ошибки предсказаний. |
| **Данные**           | - **Источник**: Датасет `labels.csv` с 7,591 изображением.<br>- **Признаки**: Изображения лиц (224x224 пикселей), метки возраста (real_age).<br>- **Особенности**: Дисбаланс возрастов (пик в 20–30 лет, редкие случаи >80 лет). |
| **Инструменты**      | - **Python**: TensorFlow, Keras, ResNet50, ImageDataGenerator.<br>- **Визуализация**: Matplotlib, Seaborn.<br>- **Метрики**: MAE, MSE. |
| **Ключевые этапы**   | 1. Загрузка и предобработка данных (масштабирование, аугментации).<br>2. Построение модели на основе ResNet50 с GlobalAveragePooling и Dense-слоем.<br>3. Обучение на 6 эпохах с Adam-оптимизатором.<br>4. Анализ ошибок и рекомендации по улучшению. |
| **Результаты**       | - **Лучшие метрики**:<br>  - MAE на тесте: **7.87**<br>  - MSE на тесте: **106.08**<br>- **Динамика обучения**: Снижение MAE с 10.99 до 6.26 за 6 эпох.<br>- **Дисбаланс**: Высокая точность на молодых возрастах, погрешности на старших. |
| **Сложности**        | - Неравномерное распределение возрастов (мало данных для >60 лет).<br>- Риск переобучения (разрыв MAE между трейном и тестом).<br>- Необходимость балансировки данных и аугментаций для редких возрастов. |
| **Бизнес-ценность**  | - Персонализация маркетинговых стратегий на основе возрастной аналитики.<br>- Автоматизация проверки возрастных ограничений (например, продажа алкоголя).<br>- Улучшение UX в мобильных приложениях (рекомендации по возрасту). |
| **Рекомендации**     | 1. Увеличить количество эпох и применить ReduceLROnPlateau.<br>2. Добавить стратифицированную разбивку данных.<br>3. Использовать аугментации для старших возрастов (например, повороты, изменения яркости). |
