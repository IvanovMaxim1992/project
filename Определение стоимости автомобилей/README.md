# Автомобильный Price Prediction: Анализ и предсказание стоимости

| **Раздел**          | **Детали**                                                                                                                                                                                                 |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цели проекта**     | 1. Прогноз рыночной цены автомобилей на основе характеристик (марка, модель, пробег, мощность и др.).<br>2. Оптимизация моделей машинного обучения для повышения точности предсказаний.<br>3. Анализ влияния редких категорий и выбросов на качество моделей. |
| **Данные**           | - **Основной датасет**: 354,369 строк с признаками:<br>  - *Технические*: Power, Kilometer, CarAgeInMonths.<br>  - *Категориальные*: VehicleType, Gearbox, FuelType, Brand, Model.<br>  - *Целевой признак*: Price.<br>- **Обработка выбросов**: Удаление аномалий по мощности, цене и году регистрации. |
| **Инструменты**      | - **Python**: pandas, numpy, scikit-learn, lightgbm, matplotlib, seaborn, fuzzywuzzy.<br>- **Предобработка**: SimpleImputer, OneHotEncoder, PolynomialFeatures, MinMaxScaler.<br>- **Модели**: LinearRegression, LGBMRegressor. |
| **Ключевые этапы**   | 1. Очистка данных: Удаление выбросов (мощность, цена), заполнение пропусков.<br>2. Обработка категориальных признаков: Fuzzy-кластеризация редких моделей (например, "range_rover" → "rangerover").<br>3. Генерация признаков: Полиномиальные признаки для числовых данных.<br>4. Обучение моделей с оптимизацией гиперпараметров. |
| **Результаты**       | - **Линейная регрессия**: RMSE **2,850** (базовая модель).<br>- **LGBMRegressor**: RMSE **1,980** (улучшение на **30%**).<br>- **Ключевые факторы**: Мощность двигателя, возраст автомобиля, пробег, марка (например, Porsche → высокая цена). |
| **Сложности**        | - Несбалансированность категорий (редкие модели, например, Trabant).<br>- Мультиколлинеарность после добавления полиномиальных признаков.<br>- Неоднозначные описания моделей (фикс через fuzzy-матчинг). |
| **Бизнес-ценность**  | - Точное ценообразование для подержанных автомобилей.<br>- Оптимизация рекомендаций клиентам на платформах продаж.<br>- Снижение рисков недооценки/переоценки автомобилей для дилеров. |
