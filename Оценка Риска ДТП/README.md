# Анализ дорожных инцидентов: Прогноз виновности и страховых рисков

| **Раздел**          | **Детали**                                                                                                                                                                                                 |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цели проекта**     | 1. Определение факторов, влияющих на виновность участников ДТП.<br>2. Прогноз страховых выплат на основе данных об инцидентах.<br>3. Выявление паттернов в данных для снижения рисков страховых компаний. |
| **Данные**           | - **Основной датасет**: 56,248 записей с признаками:<br>  - *Категориальные*: тип участника (car, building, road signs), трезвость (had not been drinking, impairment unknown),<br>  - *Числовые*: страховая премия, возраст автомобиля, время суток.<br>- **Целевые признаки**: at_fault (виновность), insurance_premium (страховая выплата). |
| **Инструменты**      | - **Python**: pandas, numpy, scikit-learn, matplotlib, seaborn.<br>- **Предобработка**: Обработка пропусков, кодирование категорий, масштабирование.<br>- **Модели**: LogisticRegression, DecisionTreeClassifier, LGBMRegressor. |
| **Ключевые этапы**   | 1. Очистка данных: Удаление выбросов (например, аномальные значения vehicle_age), заполнение пропусков в insurance_premium.<br>2. Визуализация: Анализ распределения виновности по времени суток, типу участника, трезвости.<br>3. Feature Engineering: Генерация признаков (например, сезонность, тип дороги).<br>4. Обучение моделей для классификации (at_fault) и регрессии (insurance_premium). |
| **Результаты**       | - **Виновность**: Лучшая модель — LGBMClassifier (F1-score **0.82**).<br>- **Страховые выплаты**: LGBMRegressor (MAE **$1,250**).<br>- **Ключевые факторы**: Трезвость участника, использование телефона (cellphone_in_use), тип дороги (road_condition_1). |
| **Сложности**        | - Дисбаланс классов в at_fault (85% невиновных).<br>- Высокая корреляция между vehicle_age и insurance_premium.<br>- Неоднозначные категории в party_sobriety (например, "impairment unknown"). |
| **Бизнес-ценность**  | - Снижение затрат страховых компаний за счет точечных проверок рискованных профилей.<br>- Рекомендации по безопасности: ограничение использования телефона за рулем, усиление контроля трезвости.<br>- Прогнозирование выплат для оптимизации тарифов. |
