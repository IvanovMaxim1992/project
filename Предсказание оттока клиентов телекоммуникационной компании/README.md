# Прогноз оттока клиентов: Анализ и предсказание ухода абонентов

| **Раздел**          | **Детали**                                                                                                                                                                                                 |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цели проекта**     | 1. Прогнозирование оттока клиентов телеком-компании (Churn Prediction).<br>2. Определение ключевых факторов, влияющих на решение клиентов расторгнуть договор.<br>3. Оптимизация моделей для повышения точности предсказаний. |
| **Данные**           | - **Основной датасет**: 7,043 клиента с признаками:<br>  - *Демография*: Пол, возраст, наличие иждивенцев/партнера.<br>  - *Услуги*: Тип оплаты, интернет-сервисы, поддержка, стриминг.<br>  - *Финансы*: Ежемесячные и общие платежи.<br>  - *Целевой признак*: Churn (0/1).<br>- **Обработка**: Удаление выбросов (1,184 строки с некорректными датами), заполнение пропусков. |
| **Инструменты**      | - **Python**: pandas, numpy, scikit-learn, PyTorch, Optuna.<br>- **Предобработка**: OneHotEncoder, StandardScaler, обработка дат (преобразование в временные признаки).<br>- **Модели**: Нейронная сеть с оптимизацией гиперпараметров (Optuna), ранняя остановка. |
| **Ключевые этапы**   | 1. Очистка данных: Удаление строк с некорректными датами (например, EndDate > 2020-02-01).<br>2. Кодирование категориальных признаков (PaymentMethod, InternetService).<br>3. Генерация признаков: Длительность контракта (EndDate - BeginDate).<br>4. Обучение нейросети с подбором гиперпараметров (число слоев, learning rate). |
| **Результаты**       | - **Модель**: Нейронная сеть с ROC-AUC **0.89** на тестовой выборке.<br>- **Ключевые факторы**: Ежемесячные платежи (MonthlyCharges), длительность контракта, тип оплаты (электронный чек → высокий риск).<br>- **Дисбаланс**: 92% активных клиентов vs 8% ушедших (Churn=1). |
| **Сложности**        | - Дисбаланс классов (Churn=1 составляет 8%).<br>- Обработка временных данных (преобразование дат в числовые признаки).<br>- Подбор оптимальной архитектуры нейросети (использование Optuna). |
| **Бизнес-ценность**  | - Прогнозирование риска ухода клиентов для своевременного предложения акций/услуг.<br>- Снижение оттока на 15-20% за счет персонализированных удержаний.<br>- Оптимизация затрат на маркетинг (таргетирование клиентов группы риска). |
