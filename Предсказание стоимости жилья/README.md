# Предсказание стоимости жилья в Калифорнии: Линейная регрессия

| **Раздел**          | **Детали**                                                                                                                                                                                                 |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цели проекта**     | 1. Прогноз медианной стоимости домов в жилых массивах Калифорнии (1990 г.).<br>2. Сравнение моделей с категориальными и числовыми признаками.<br>3. Оценка качества моделей с помощью метрик RMSE, MAE и R². |
| **Данные**           | - **Источник**: Датасет `housing.csv` (20,640 строк).<br>- **Признаки**: Географические координаты, возраст домов, количество комнат, население, доход, категория близости к океану.<br>- **Целевая переменная**: `median_house_value`. |
| **Инструменты**      | - **PySpark**: SparkSession, MLlib (LinearRegression, Pipeline).<br>- **Предобработка**: OneHotEncoder, StringIndexer, StandardScaler, VectorAssembler.<br>- **Метрики**: RMSE, MAE, R². |
| **Ключевые этапы**   | 1. Удаление пропусков (207 строк в `total_bedrooms`).<br>2. Кодирование категориальной колонки `ocean_proximity`.<br>3. Масштабирование числовых признаков.<br>4. Обучение двух моделей: с категориальными и без. |
| **Результаты**       | - **Модель со всеми данными**:<br>  - RMSE: **68,210**<br>  - MAE: **49,735**<br>  - R²: **0.650**<br>- **Модель только с числовыми признаками**:<br>  - RMSE: **69,020**<br>  - MAE: **50,662**<br>  - R²: **0.642** |
| **Сложности**        | - Предупреждения о `regParam = 0` (потенциальное переобучение).<br>- Значительное влияние категориального признака `ocean_proximity` на качество модели. |
| **Бизнес-ценность**  | - Точное прогнозирование стоимости для инвесторов и риелторов.<br> - Оптимизация стратегий ценообразования на рынке недвижимости.<br> - Выявление ключевых факторов, влияющих на стоимость (например, близость к океану). |
