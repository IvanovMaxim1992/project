# Прогнозирование спроса: Анализ временных рядов и оптимизация модели

| **Раздел**          | **Детали**                                                                                                                                                                                                 |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цели проекта**     | 1. Прогнозирование количества заказов на основе временных данных.<br>2. Оценка точности модели и выявление закономерностей в данных.<br>3. Разработка рекомендаций для улучшения предсказаний. |
| **Данные**           | - **Источник**: Часовые данные о количестве заказов.<br>- **Признаки**: Временные метки, исторические значения спроса.<br>- **Целевая переменная**: Количество заказов в следующий час. |
| **Инструменты**      | - **Python**: pandas, scikit-learn, matplotlib.<br>- **Модель**: Базовая модель регрессии (предположительно, линейная или дерево решений).<br>- **Метрики**: RMSE, визуализация трендов. |
| **Ключевые этапы**   | 1. Предобработка данных: Устранение аномалий, агрегация по часам.<br>2. Обучение модели на исторических данных.<br>3. Визуальный анализ предсказаний vs реальных значений.<br>4. Оценка RMSE на тестовой выборке. |
| **Результаты**       | - **RMSE на тесте**: **41.39** (приемлемая точность, но есть отклонения на пиках).<br>- **Тренды**: Модель корректно отражает основные паттерны, но недооценивает пики спроса.<br>- **Рекомендации**: Добавить признаки (например, день недели), использовать градиентный бустинг. |
| **Сложности**        | - Нестабильность предсказаний на экстремальных значениях (пики/провалы).<br>- Ограниченное количество данных для обучения. |
| **Бизнес-ценность**  | - Оптимизация логистики и распределения ресурсов за счет прогнозирования спроса.<br>- Снижение рисков перегрузок или простоя.<br>- Возможность масштабирования модели для долгосрочных прогнозов. |
