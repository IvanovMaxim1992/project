# Прогнозирование закрытия стартапов: Анализ и классификация

| **Раздел**          | **Детали**                                                                                                                                                                                                 |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цели проекта**     | 1. Прогнозирование закрытия стартапов (статус: operating/closed).<br>2. Анализ ключевых факторов, влияющих на успех проектов.<br>3. Оптимизация модели для минимизации ложных предсказаний. |
| **Данные**           | - **Основной датасет**: 50,000+ стартапов с признаками:<br>  - *Финансы*: Количество раундов финансирования, общая сумма инвестиций.<br>  - *Временные метки*: Даты основания, первого/последнего финансирования, закрытия.<br>  - *Категории*: category_list, region, country_code.<br>  - *Целевой признак*: status (operating/closed). |
| **Инструменты**      | - **Python**: pandas, numpy, scikit-learn, matplotlib, seaborn.<br>- **Предобработка**: Обработка пропусков (17% строк с missing values), кодирование категорий, масштабирование.<br>- **Модели**: Логистическая регрессия, Random Forest, XGBoost. |
| **Ключевые этапы**   | 1. Анализ пропусков: Заполнение дат закрытия (closed_at) фиксированным значением (2018-01-01).<br>2. Feature Engineering: Генерация признаков (длительность существования, время до первого финансирования).<br>3. Борьба с дисбалансом: SMOTE для класса "closed" (менее 30% данных).<br>4. Подбор гиперпараметров с GridSearchCV. |
| **Результаты**       | - **Лучшая модель**: XGBoost (F1-score: **0.82** для класса closed).<br>- **Ключевые факторы**:<br>  - Высокая корреляция: funding_total_usd, время до первого раунда финансирования.<br>  - Критичные категории: category_1, category_5 (наибольшая связь с закрытием).<br>- **Метрики**:<br>  - ROC-AUC: **0.91**<br>  - Precision: **0.78** (closed), **0.89** (operating). |
| **Сложности**        | - Значительное количество пропусков в категориальных признаках (например, region: 692 уникальных значения).<br>- Неоднозначность дат (closed_at заполнен фиктивными значениями для активных проектов).<br>- Высокая размерность данных после OHE-кодирования. |
| **Бизнес-ценность**  | - Минимизация рисков для инвесторов за счет раннего выявления "рискованных" стартапов.<br>- Оптимизация стратегии финансирования (фокус на проекты с низким time_to_first_funding).<br>- Анализ уязвимых категорий (например, category_5) для реструктуризации портфеля. |
