# Прогноз качества молока: Анализ факторов и оптимизация стада

| **Раздел**          | **Детали**                                                                                                                                                                                                 |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цели проекта**     | 1. Прогнозирование качества молока (жирность, белок, вкус) на основе данных о коровах.<br>2. Выявление ключевых факторов, влияющих на удой и характеристики молока.<br>3. Оптимизация стада для повышения продуктивности. |
| **Данные**           | - **Основные датасеты**: 634 записи с параметрами коров (порода, возраст, тип пастбища) и молока (удой, жирность, белок, вкус).<br>- **Целевые признаки**: Жирность (%), уровень белка (%), вкус (вкусно/не вкусно). |
| **Инструменты**      | - **Python**: pandas, numpy, scikit-learn, matplotlib, seaborn.<br>- **Предобработка**: Заполнение пропусков (медиана по группам), удаление выбросов, кодирование категорий.<br>- **Модели**: Линейная регрессия, DecisionTreeClassifier. |
| **Ключевые этапы**   | 1. Очистка данных: Удаление аномальных значений (например, удой > 10,000 кг).<br>2. EDA: Корреляция между жирностью и белком (r=0.69), влияние породы на удой.<br>3. Feature Engineering: Генерация признаков (СПО, энергетическая ценность корма).<br>4. Обучение моделей для предсказания вкуса и химических показателей. |
| **Результаты**       | - **Линейная регрессия (жирность)**: R² **0.72**, MAE **0.15%**.<br>- **Классификация вкуса**: Accuracy **82%** (F1-score: **0.79** для "не вкусно").<br>- **Ключевые факторы**: Тип пастбища (холмистое → выше жирность), порода папы-быка (Айдиал → стабильный белок). |
| **Сложности**        | - Несбалансированность классов во вкусе молока (67% "вкусно").<br>- Высокая корреляция между жирностью и белком (мультиколлинеарность).<br>- Редкие категории в породах (например, "Вис Бик Айдиал"). |
| **Бизнес-ценность**  | - Повышение качества молока за счет оптимального подбора пород и пастбищ.<br>- Снижение риска покупки непродуктивных коров (анализ данных перед инвестированием).<br>- Рекомендации по кормлению (ЭКЕ/СПО для улучшения жирности). |
