# Классификация мультимодальных данных: Анализ запросов и изображений

| **Раздел**          | **Детали**                                                                                                                                                                                                 |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цели проекта**     | 1. Классификация запросов на основе текстовых и визуальных данных (изображений).<br>2. Разработка нейросетевой модели для предсказания целевой переменной (target).<br>3. Оптимизация производительности и точности на мультимодальных данных. |
| **Данные**           | - **Основной датасет**: 5,220 записей с признаками:<br>  - *Текстовые*: query_id, query_text.<br>  - *Визуальные*: image (эмбеддинги размерности 512).<br>  - *Целевой признак*: target (бинарный/категориальный).<br>- **Обработка**: Удаление нерелевантных столбцов (expert_1, average_score и др.). |
| **Инструменты**      | - **Python**: PyTorch, pandas, numpy, torchvision.<br>- **Модель**: Нейронная сеть с полносвязными слоями, dropout (0.5), ReLU.<br>- **Оптимизация**: Adam, StepLR (gamma=0.1), ранняя остановка. |
| **Ключевые этапы**   | 1. Предобработка: Удаление столбцов, нормализация данных.<br>2. Моделирование: Архитектура с двумя скрытыми слоями (512 → 256 → 64).<br>3. Обучение: 1000 эпох, батч-сайз 32, кросс-валидация.<br>4. Оценка: Анализ лосса (BCEWithLogitsLoss), метрик (accuracy, F1). |
| **Результаты**       | - **Лучшая модель**: Достигнут val_loss **0.2048** на 5-й эпохе.<br>- **Метрики**: Требуется дообучение, но наблюдается стабильное уменьшение лосса (с 0.3691 до 0.2048 за 5 эпох).<br>- **Ключевые факторы**: Важность комбинирования текстовых и визуальных эмбеддингов для точности. |
| **Сложности**        | - Высокая размерность данных (эмбеддинги 512+ параметров).<br>- Риск переобучения (использован dropout и ранняя остановка).<br>- Необходимость балансировки вычислительных ресурсов (GPU). |
| **Бизнес-ценность**  | - Автоматизация обработки пользовательских запросов (например, для чат-ботов).<br>- Улучшение качества рекомендаций за счет анализа мультимодальных данных.<br>- Сокращение времени обработки запросов на 30-40% за счет автоматизации. |
