# Анализ доходов оператора связи: Оптимизация тарифов и прогноз выручки

| **Раздел**          | **Детали**                                                                                                                                                                                                 |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цели проекта**     | 1. Прогнозирование ежемесячной выручки на основе данных о пользователях.<br>2. Анализ эффективности тарифных планов (ultra/free).<br>3. Выявление ключевых факторов, влияющих на доход оператора связи. |
| **Данные**           | - **Основной датасет**: 11,329 записей с признаками:<br>  - *Пользователи*: user_id, имя, возраст, город.<br>  - *Использование услуг*: calls_duration, messages_count, mb_used.<br>  - *Финансы*: revenue, other_services_revenue.<br>  - *Тарифы*: ultra/free.<br>- **Целевая переменная**: revenue (ежемесячная выручка). |
| **Инструменты**      | - **Python**: pandas, numpy, scikit-learn, matplotlib, seaborn.<br>- **Предобработка**: Обработка пропусков, агрегация данных по пользователям.<br>- **Модели**: Линейная регрессия, кластеризация (K-means). |
| **Ключевые этапы**   | 1. Агрегация данных: Группировка по user_id и месяцам для расчета средних показателей.<br>2. EDA: Анализ распределения выручки, сравнение тарифов ultra и free.<br>3. Feature Engineering: Генерация признаков (соотношение услуг и дохода).<br>4. Построение модели для прогнозирования revenue. |
| **Результаты**       | - **Тариф Ultra**: Средняя выручка **4,234 руб.** против **2,967 руб.** у free.<br>- **Ключевые факторы**: Количество дополнительных услуг (other_services_count), использование мобильного интернета (mb_used).<br>- **Модель**: R² **0.89** на тестовой выборке (линейная регрессия). |
| **Сложности**        | - Несбалансированность данных (больше пользователей тарифа free).<br>- Высокая корреляция между mb_used и revenue (r=0.78).<br>- Необходимость агрегации сырых данных для анализа. |
| **Бизнес-ценность**  | - Оптимизация тарифных планов за счет анализа потребления услуг.<br>- Увеличение дохода от дополнительных услуг (например, SMS-пакеты).<br>- Прогнозирование выручки для планирования бюджета компании. |
