# Прогноз температуры: Анализ и подготовка данных для нейросети

| **Раздел**          | **Детали**                                                                                                                                                                                                 |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цели проекта**     | 1. Прогнозирование температуры (Temperature (K)) на основе комбинированных данных (числовые и категориальные признаки).<br>2. Подготовка данных для обучения нейронной сети.<br>3. Улучшение качества модели за счет генерации полиномиальных признаков. |
| **Данные**           | - **Источник**: Датасет `6_class.csv` (240 записей, 7 колонок).<br>- **Признаки**:<br>  - *Числовые*: Не указаны явно (предположительно, параметры среды/процессов).<br>  - *Категориальные*: Требуют кодирования (OneHotEncoder).<br>- **Целевая переменная**: `Temperature (K)` (кельвины). |
| **Инструменты**      | - **Python**: pandas, scikit-learn (OneHotEncoder, train_test_split).<br>- **Предобработка**: Масштабирование, кодирование категорий, генерация полиномиальных признаков. |
| **Ключевые этапы**   | 1. Загрузка данных с обработкой путей (локальных/серверных).<br>2. Разделение на признаки (X) и целевую переменную (y).<br>3. Обработка категориальных данных (OHE с `drop='first'`).<br>4. Масштабирование числовых признаков.<br>5. Генерация полиномиальных признаков для нелинейных зависимостей. |
| **Результаты**       | - Данные подготовлены для обучения нейросети (X_train, X_test).<br>- Устранена мультиколлинеарность через `drop='first'` в OHE.<br>- Применены преобразования для повышения устойчивости модели (например, масштабирование). |
| **Сложности**        | - Необходимость работы с категориальными признаками (высокая размерность после OHE).<br>- Риск переобучения из-за полиномиальных признаков.<br>- Отсутствие явного указания числовых признаков в датасете. |
| **Бизнес-ценность**  | - Точное прогнозирование температуры для оптимизации промышленных/научных процессов.<br>- Сокращение ресурсных затрат за счет автоматизации анализа данных.<br>- Возможность интеграции в системы реального времени для мониторинга. |
