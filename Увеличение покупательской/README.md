# Прогноз покупательской активности: Анализ и оптимизация стратегий

| **Раздел**          | **Детали**                                                                                                                                                                                                 |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цели проекта**     | 1. Прогнозирование покупательской активности (бинарная классификация).<br>2. Выявление ключевых факторов, влияющих на снижение/рост активности.<br>3. Разработка рекомендаций для повышения вовлеченности клиентов. |
| **Данные**           | - **Market File**: 1,300 записей с признаками:<br>  - *Активность*: Маркет_актив_6_мес (среднее 4.25), Маркет_актив_тек_мес (среднее 4.01).<br>  - *Временные метки*: Длительность (среднее 601.9 дней).<br>- **Market Money**: 3,900 записей с выручкой (среднее 5,025.7 руб.).<br>- **Категориальные признаки**: Тип сервиса (премиум/стандарт), популярные категории (товары для детей, косметика), период (текущий/предыдущий месяц). |
| **Инструменты**      | - **Python**: pandas, scikit-learn, SHAP.<br>- **Предобработка**: OneHotEncoder (для категорий), MinMaxScaler (для числовых признаков).<br>- **Модель**: LogisticRegression (C=1, penalty='l1', solver='liblinear'). |
| **Ключевые этапы**   | 1. Исправление опечаток (например, "стандартт" → "стандарт").<br>2. Масштабирование числовых признаков и кодирование категорий.<br>3. Обучение модели с подбором гиперпараметров (GridSearchCV).<br>4. Анализ SHAP-значений для интерпретации важности признаков. |
| **Результаты**       | - **Лучшая модель**: LogisticRegression (точность на трейне **0.8998**).<br>- **Ключевые факторы**:<br>  - Отрицательное влияние: Неоплаченные продукты (квартал).<br>  - Положительное влияние: Время на сайте (минуты текущий месяц).<br>- **Статистика**: Market File содержит данные о длительности активности (max 2,166 дней), Market Money — о выручке (max 216,647 руб.). |
| **Сложности**        | - Наличие опечаток в категориальных признаках (например, "предыдцщий_месяц").<br>- Необходимость балансировки классов (анализ SHAP указывает на дисбаланс).<br>- Высокая размерность после кодирования категорий. |
| **Бизнес-ценность**  | - Персональные скидки для клиентов с неоплаченными товарами.<br>- Улучшение мобильного UX для повышения времени на сайте.<br>- Оптимизация рассылок (например, "Товары для детей" → сегментированная реклама).<br>- Рекомендации требуют проверки через A/B-тесты. |
